# Brand

Ship everything under **Radius**. Logos live in `/Logotype`.

## Reserved alt: Archibold
- Domain candidate: `archibold.ai`
- Status: **reserved alt only** — not used in product UI, metadata, or docs URLs for v1

## Voice
- Clear, calm, confident
- Never ask the user to “configure a model” or “open a file”
- Prefer “your site” over “project” in everyday copy

## Radius Spiral Spinner
The signature loading state while the **Router** chooses the best path and agents work.

- **Visual:** Gold Fibonacci spiral (matches logotype), slow turn + draw animation + soft glow
- **Copy:** Plain English only — e.g. “Choosing the best path…”, “Thinking it through…”, “Refining quickly…”
- **Never show:** model names, tokens, or “GPT/Claude” in the everyday UI
- **Component:** `src/components/radius-spiral-spinner.tsx`
